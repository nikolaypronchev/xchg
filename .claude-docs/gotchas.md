# Gotchas

- **`local h="$1" d="${HUB_PATH[$h]}"` не работает под `set -u`.** Раскрытие всех значений происходит до присваивания, `$h` ещё не задан. Всегда две команды: `local h="$1"; local d=...`.
- **`{ …; [ cond ] && cmd; } >> file` под `set -e` роняет скрипт**, если `cond` ложно и это последняя команда группы/функции. Заканчивать группу `true` или писать `if`.
- **`exit 3` внутри `$(...)` не выходит из скрипта** — только из подстановки. Поэтому `cmd_agent` сначала делает `a=$(agent_name)` (присваивание с провалившейся подстановкой под `set -e` завершает скрипт с её кодом), а не `echo "$(login)/$(agent_name)"`.
- **`git mv` не знает `-q`** (в отличие от `git rm -q`).
- **При `git rebase` «ours» = upstream (чужое), «theirs» = переигрываемый коммит (моё).** `store_resolve_conflict` делает `checkout --ours`, чтобы принять чужую версию — это не опечатка.
- **`store push` намеренно не делает pull перед зеркалированием.** Иначе чужая правка общего файла тихо перетиралась бы локальной; коммит на старый HEAD + `pull --rebase` дают настоящий конфликт, который сохраняется в `<file>.conflict.<host>`.
- **`mirror_dir` асимметричен по тегам host:** `push` не копирует и не удаляет файлы чужого host (их источник — другая машина), `pull` не удаляет файлы своего host (ещё не запушенное состояние). Тег = второй компонент имени (`SESSION.<host>.md`), поэтому `foo.bar.md` тоже считается «чужим» — это допустимо.
- **`xchg who <q>` — подстрочный поиск** («оля» находит и «коля»), а `send` резолвит только точное совпадение login/имени/алиаса (casefold). Так было и в v1.
- **`sync_hubs` может убить `git pull` по дедлайну посреди rebase** — `hub_sync` при старте проверяет `.git/rebase-merge|rebase-apply` и делает `rebase --abort`.
- **`self_update` молчит в грязном клоне** (`git status --porcelain` не пуст) — чтобы не дёргать репо разработчика. На чистой установке пользователя pull идёт с тем же дебаунсом `--max-age`.
- **Тесты запускаются из репо xchg, поэтому cwd — git-репо `xchg`:** `xchg agent` без `cd` даёт агента `xchg`. В `tests/run.sh` секция store экспортирует `XCHG_AGENT=trends`.
- **`hostname` под WSL = имя Windows-машины**, поэтому `host` никогда не вычисляется повторно, только читается из конфига (SPEC §4.9).
